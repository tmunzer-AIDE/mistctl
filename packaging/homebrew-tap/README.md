# tmunzer-AIDE Homebrew tap

Homebrew casks for [mistctl](https://github.com/tmunzer-AIDE/mistctl), a
read-only, kubectl-style command line client for the Juniper Mist API.

```sh
brew install --cask tmunzer-AIDE/tap/mistctl
```

Installing by the full name trusts only this cask. To use the short name
`mistctl`, trust the tap first:

```sh
brew tap tmunzer-AIDE/tap
brew trust tmunzer-AIDE/tap
brew install --cask mistctl
```

`Casks/mistctl.rb` is generated by GoReleaser on every mistctl release. Do
not edit it by hand.
