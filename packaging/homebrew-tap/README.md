# tmunzer-AIDE Homebrew tap

Homebrew cask for [mistctl](https://github.com/tmunzer-AIDE/mistctl), a
read-only, kubectl-style command line client for the
[Juniper Mist](https://www.juniper.net/us/en/products/mist-ai.html) API.
Works on macOS (Apple silicon and Intel) and Linux (amd64 and arm64).

```console
$ mistctl get devices --site HQ
NAME       TYPE     MODEL    MAC            IP          STATUS         VERSION   UPTIME
ap-lobby   ap       AP45     5c5b35000001   10.0.0.10   connected      0.14.1    1d1h
sw-core    switch   EX4100   5c5b35000002   -           disconnected   -         -
```

## Install

```sh
brew install --cask tmunzer-AIDE/tap/mistctl
```

Installing by the full name trusts only this cask. To use the short name
`mistctl`, trust the tap once:

```sh
brew tap tmunzer-AIDE/tap
brew trust tmunzer-AIDE/tap
brew install --cask mistctl
```

Shell completions for bash, zsh and fish are installed with the cask. The
macOS binary is signed with a Developer ID certificate and notarized by
Apple; check it with `spctl -a -vvv -t install "$(command -v mistctl)"`.

## Upgrade and uninstall

```sh
brew upgrade --cask mistctl
brew uninstall --cask mistctl
```

Uninstalling leaves your contexts in `~/Library/Application Support/mistctl`
(macOS) or `~/.config/mistctl` (Linux).

## Get started

```sh
echo "$MIST_TOKEN" | mistctl config set-context prod --cloud global01 --token-stdin --org "ACME"
mistctl whoami
mistctl get sites
```

Use an API token with the read-only (Observer) role. See the
[mistctl README](https://github.com/tmunzer-AIDE/mistctl#readme) for every
command and resource, and report problems in the
[mistctl issues](https://github.com/tmunzer-AIDE/mistctl/issues), not here.
