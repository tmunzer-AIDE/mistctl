# tmunzer-AIDE Scoop bucket

Scoop manifest for [mistctl](https://github.com/tmunzer-AIDE/mistctl), a
read-only, kubectl-style command line client for the
[Juniper Mist](https://www.juniper.net/us/en/products/mist-ai.html) API.
Works on Windows amd64 and arm64.

```console
PS> mistctl get devices --site HQ
NAME       TYPE     MODEL    MAC            IP          STATUS         VERSION   UPTIME
ap-lobby   ap       AP45     5c5b35000001   10.0.0.10   connected      0.14.1    1d1h
sw-core    switch   EX4100   5c5b35000002   -           disconnected   -         -
```

## Install

```powershell
scoop bucket add mistctl https://github.com/tmunzer-AIDE/scoop-bucket
scoop install mistctl
```

## Upgrade and uninstall

```powershell
scoop update
scoop update mistctl
scoop uninstall mistctl
```

Uninstalling leaves your contexts in `%AppData%\mistctl`.

## Shell completion

Add this line to your PowerShell profile (`notepad $PROFILE`):

```powershell
mistctl completion powershell | Out-String | Invoke-Expression
```

## Get started

```powershell
$env:MIST_TOKEN | mistctl config set-context prod --cloud global01 --token-stdin --org "ACME"
mistctl whoami
mistctl get sites
```

Use an API token with the read-only (Observer) role. See the
[mistctl README](https://github.com/tmunzer-AIDE/mistctl#readme) for every
command and resource, and report problems in the
[mistctl issues](https://github.com/tmunzer-AIDE/mistctl/issues), not here.
